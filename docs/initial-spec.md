- ブラウザで動作するタスク管理アプリ
- 基本的には自分のみで使う前提
- タスクの段階は「すぐやる」「近いうちにやる」「将来やる」
- タスクはかかる時間の見積もりを設定できる
- タスク一覧はドラッグで入れ替えることができる
- タスクを小タスクに分解することができ、一覧から折りたたみで開閉できる
- データの保存はlocalstorageで行う他、現在の状態をエクスポート、インポートができる
- 週ごとのタイムラインを表示し、タスクを配置することができる
- カレンダー（月ごと）に、配置済みのタスク数を表示する
- 仕様は不明瞭で、使いながら調整したい。まずはこの手のアプリの定番機能を実装して、実際に使い始めることを目指す。
